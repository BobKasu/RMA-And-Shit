# RMA And Shit

### Description
RMA Ecosystem is a custom interactive ecosystem that uses the booth to provide cool games, utilies, animations, and more in Rate My Avatar 2. It lets players quickly hop and interact with it. It uses remote events to edit the booth's text, image, and colors, and makes use of Roblox's wide and versatile tools to open up more possibilites like using jumping as inputs instead of chat.
